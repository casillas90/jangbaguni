# 🛒 스마트 장바구니 (평생 소장용)

인터넷 연결이나 서버 구동 없이도 브라우저만 있으면 평생 무료로 안전하게 사용할 수 있는 스마트 장바구니 웹앱입니다.

---

## 🚀 바로 실행하는 방법
1. **문서 > 장바구니** 폴더로 이동합니다.
2. `index.html` 파일을 더블 클릭하거나, `장바구니_실행.command`를 더블 클릭하면 기본 브라우저(Safari, Chrome 등)에서 즉시 열립니다.
3. 바탕화면에 바로가기를 두고 싶으시다면 `index.html` 또는 `장바구니_실행.command`를 복사/가상본 생성하여 바탕화면에 두시면 됩니다.

---

## 📱 스마트폰(아이폰 / 갤럭시)에서 앱처럼 쓰는 법
장볼 때 스마트폰으로 편리하게 사용하시려면:
1. `index.html` 파일을 스마트폰으로 전송(카카오톡 나에게 보내기, iCloud Drive, Google Drive, 또는 네이버 MYBOX 등)하여 열거나, 브라우저로 엽니다.
2. **아이폰 (Safari)**: 하단 **공유 버튼(네모+화살표)** 누른 뒤 **[홈 화면에 추가]** 클릭
3. **갤럭시/안드로이드 (Chrome)**: 우측 상단 **더보기 메뉴(점 3개)** 누른 뒤 **[홈 화면에 추가]** 클릭
4. 휴대폰 바탕화면에 진짜 장바구니 앱 아이콘이 생겨 인터넷 없이도 언제든 실행됩니다!

---

## ✨ 핵심 기능 안내
1. **실시간 자동 합산**:
   - 총 예정 금액, 카트에 담은 완료 금액, 남은 금액이 1원 단위까지 실시간 자동 계산됩니다.
2. **장보기 완료 & 과거 영수증 보관함**:
   - 오늘 장보기를 마친 후 `오늘 장보기 완료 & 기록에 저장하기`를 누르면 과거 영수증 탭에 날짜/금액별로 차곡차곡 영구 보관됩니다.
   - 지난번에 산 품목들을 클릭 한 번으로 다시 장바구니에 담을 수도 있습니다.
3. **자주 사는 단골 품목 관리**:
   - 매주/매달 자주 사는 식재료(계란, 우유, 대파 등)를 나만의 단골 목록에 등록해두면 클릭 한 번으로 빠르게 추가됩니다.
4. **데이터 백업 및 복원 (영구 보관)**:
   - 우측 상단 디스켓 아이콘(💾)을 누르면 내 모든 장바구니 데이터(현재 목록, 과거 영수증, 단골 품목)를 `.json` 파일로 안전하게 다운로드할 수 있습니다.
   - 폰이나 PC를 바꾸더라도 백업 파일만 불러오면 모든 기록이 100% 복원됩니다.
5. **다크 모드 / 인쇄 (A4 영수증) / 카카오톡 목록 복사**:
   - 밤이나 어두운 곳에서도 눈이 편한 다크 모드(🌙/☀️)
   - 종이나 PDF로 깔끔하게 출력하는 인쇄 기능
   - 카톡이나 문자로 장보기 목록을 깔끔하게 공유하는 복사 기능
